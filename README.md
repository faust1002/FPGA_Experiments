# FPGA Experiments

A hands-on FPGA development project targeting the **Xilinx Artix-7** (xc7a100tcsg324-1),
focused on implementing and synthesizing digital designs using a structured, script-driven
Vivado workflow.

## Project Structure

```
.
├── rtl/                  # Verilog source files
├── tb/                   # Testbenches (cocotb)
├── scripts/              # Vivado Tcl scripts
│   ├── create_project.tcl
│   ├── update_project.tcl
│   └── run_synth.tcl
├── Makefile
└── .pre-commit-config.yaml
```

## Build System

The project uses a `make`-based build system wrapping Vivado in batch mode. All Vivado
interaction is driven through Tcl scripts — no GUI required.

| Target | Description |
|--------|-------------|
| `make create` | Create a new Vivado project from scratch |
| `make update` | Sync RTL file additions/removals into an existing project |
| `make synth` | Run synthesis (requires `create` first) |
| `make sim` | Run cocotb simulations |
| `make clean` | Remove all build artifacts |
| `make help` | Show available targets |

### Prerequisites

- Vivado (tested with 2024.2)
- GNU Make
- Python 3 + cocotb (for simulation)
- pytest (for running testbenches)
- pre-commit (for code quality hooks)
- Verilator (for linting and simulation)
- isort (Python import sorting)
- pylint (Python static analysis)
- mypy (Python type checking)
- scipy (for FIR simulation)
- numpy (for FIR simulation)

### Quick Start

```bash
# Install Python dependencies
pip install -r requirements.txt

# Set up code quality hooks
pre-commit install

# Build and simulate
make create   # Create the Vivado project
make synth    # Run synthesis
make sim      # Run testbenches
```
